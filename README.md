# Global EV Adoption Analysis Dashboard | Power BI

## 📌 Project Overview
This project contains interactive **Power BI dashboards** created to analyze and visualize **Global Electric Vehicle (EV) adoption trends**.  
The dashboards help understand EV growth, regional performance, market penetration, and category-wise adoption patterns.

These dashboards are designed for quick decision-making using clean visuals, KPIs, and filters.

---

## 🎯 Objectives
- Track EV adoption growth over time
- Identify top-performing regions/countries/states
- Compare EV categories (BEV, PHEV, FCEV)
- Understand market penetration and trend insights
- Create an interactive report for business analysis

---

## 📊 Dashboards Included
### ✅ Dashboard 1: EV Adoption Overview
Key focus:
- Total EV count / sales overview
- Year-wise EV growth trend
- Top regions/locations by EV adoption
- Category split (BEV/PHEV/FCEV)

### ✅ Dashboard 2: Penetration & Regional Analysis
Key focus:
- Market penetration insights
- Region-wise EV adoption comparison
- High adoption areas and contribution %

### ✅ Dashboard 3: Category & Trend Insights
Key focus:
- EV type comparison across regions
- Performance tracking by year and category
- Trends and growth patterns

---

## 🛠 Tools & Technologies Used
- **Power BI Desktop**
- Data Cleaning & Transformation using **Power Query**
- **DAX** (for measures/KPIs)
- Interactive Visuals (cards, charts, maps, slicers)

---

## 🔍 Key Insights (Highlights)
- EV adoption is increasing year-by-year
- Some regions show faster growth and higher penetration
- BEVs contribute major adoption compared to other EV types
- Category-wise and region-wise comparison gives strong market understanding
